CineLog API in motion

Every request to CineLog passes the same five checks inside Engine E4 (CN & Web Tech), in the same order: Token, Rate limit, Role, Input, State. Pick a request and a situation, then press Play. The first check that fails decides the status code, and nothing after it runs. Responses are the real ones from the running server.
