CineLog Transactions in motion

One user action is one transaction in Engine E2 (Storage & Transaction): it commits fully or rolls back fully. Each scene shows two things arriving at the same moment. Press Play to watch who wins, who is rejected and what is left in the database. The transactions are now built on SQLite in WAL mode with BEGIN IMMEDIATE for writes (backend/app/db.py, workflow.py, routers on branch sprint-2). Each scene ends with an In the build box: what the code does today, the test that proves it and what is still being finished.
